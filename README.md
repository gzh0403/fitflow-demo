# FitFlow 演示样品（P2 可交互原型）

这是一份公开的演示样品，使用虚构演示数据，不是商业产品。预期公开地址：https://gzh0403.github.io/fitflow-demo/

这是健身工作室（普拉提 / 瑜伽 / 精品工作室）产品的可视化交互原型，供总负责人审核。不是正式小程序，未上线，未接入真实支付或云环境。

**产品工作名：FitFlow。** 界面确认前请继续使用这个名字。文档里另有一个备选品牌名，属于建议，待确认，尚未锁定。

演示门店「青石普拉提」及全部会员、教练、电话、地址均为虚构数据。

## 如何打开

任选一种方式即可：

1. **公开演示页**  
   用浏览器打开：

   https://gzh0403.github.io/fitflow-demo/

2. **直接打开文件**  
   用浏览器打开本仓库根目录的 `index.html`。

3. **本地预览服务**  
   在本目录运行：

   `./serve.sh`

   然后在浏览器打开 http://127.0.0.1:8765/

建议使用 Chrome、Safari 或 Edge 的较新版本。打开后，顶部深色条是「演示工具条」：可切换顾客 / 店员 / 老板，也可一键重置演示数据；并写明本样品为虚拟数据，以及「试用视觉 / 色值未锁定，待创始人确认」。手机宽度下这些提示也会保留。正式产品不会保留这一条。

宽屏下，店员端和老板端会显示为管理后台布局；手机宽度下使用底部导航。请两种宽度都看一看。

## 建议体验顺序

1. 顾客端：首页 → 周课表 → 预约一节有余位的团课 → 查看课包余次变化。
2. 打开一节「满员」课，体验候补（这是演示项，不是每家店最小可销售产品的必交项）。
3. 在「我的预约」里，取消一节距开课超过 4 小时的课，确认次数退回、名额释放。
4. 看一节即将开课的预约：应提示已过取消窗口，不能自行取消。
5. 预约一节私教。再到老板端把「私教确认方式」改为手动，重新约一节，观察进入「待确认」，由店员确认或拒绝。
6. 店员端：今日课次 → 课次名单 → 签到，再回顾客端看余次（预占转为已核销）。
7. 老板端：看经营看板数字是否与刚才的操作一致；可改课表、教室容量、发放演示课包。

更完整的点击路径见 `docs/页面导航说明.md`。
