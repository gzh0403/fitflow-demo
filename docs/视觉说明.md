# FitFlow 视觉说明（试用方案，尚未锁定）

本原型的视觉只是 P2 起点，用来让负责人先看到产品气质。**色值、字体组合和细节均未锁定，待创始人确认后才能视为设计方向定稿。** 不要把下面的数字写成已经批准的品牌规范。

## 方向

按已原则同意的起点准备：清爽、安静、适合精品工作室。留白较多，字体克制，有运动精品感，避免做成通用后台模板或简陋演示风。

明确没有使用木序的昭和复古：没有深色木纹、印章、和风纹样、做旧纸感，也没有怀旧餐饮气质。

演示门店用「青石普拉提」作为虚构馆名，是为了展示换品牌后的门店面貌；产品工作名在工具条上仍写作 FitFlow。

## 试用色值（未锁定）

下列色值来自 P1 建议的深松绿、暖砂色、赤陶色、鼠尾草绿，并在原型中试用。它们是起点，不是定稿。

| 用途 | 试用色 | 色值 |
|---|---|---|
| 深松绿（主文字、导航、深色工具条） | 深松绿 | `#1F3A34` |
| 深松绿加深 | 工具条与首页品牌区 | `#122621` |
| 暖砂色（页面背景） | 暖砂 | `#F6F1E8` |
| 卡片与纸色 | 暖砂浅 / 象牙 | `#FBF8F3`、`#FFFCF7` |
| 赤陶色（主要按钮、少量强调） | 赤陶 | `#C46A4A` |
| 鼠尾草绿（余位、成功、签到） | 鼠尾草 | `#7A8F6A` |
| 墨色正文 | 近深松的墨色 | `#1C2724` |
| 次要文字 | 灰绿 | `#5E6A65` |
| 分割线 | 暖砂线 | `#E6DFD4` |

满员、缺席、警告等状态另外用了收敛的红棕色和暖黄色，只作提示，不是品牌主色。

## 字体与版式

为避免把原型绑在外部字体账号或可能不稳定的线上字库，本样品使用系统字体：

- 中文与界面：苹方、冬青黑体、Noto Sans SC、微软雅黑等无衬线字体
- 品牌英文「FitFlow」：宋体一类衬线字体，字距略宽，用来区分产品名和界面文字

标题字号克制，行距较松，卡片圆角偏柔，按钮多为胶囊形。宽屏课表用七日网格，手机用横向日期条加列表。

## 气质上希望被看到的感觉

像一间安静的精品工作室小程序，而不是健身房促销页，也不是密集的后台系统。首页品牌区用深松绿压住画面，其余页面以暖砂底和留白为主，赤陶只出现在需要行动的地方。

如果创始人认为还不够静、不够暖，或希望更接近某一类参照门店，可以在确认视觉时直接改方向。在此之前，以上方案只作为可讨论的试用。

## 建议，待确认：备选品牌名

界面确认前，产品工作名必须继续使用 **FitFlow**，不得把备选名写成已锁定。

建议备选名：**澄所**。

取「澄」的清透与「所」的安放，想表达把身体安放在一处干净、安静的练习空间。若觉得不够像互联网产品名，也可以继续只用 FitFlow，或另定。是否采用，请创始人确认。
