# FitFlow 页面导航说明

面向审核用。不需要读代码，按下面的路径在浏览器里点即可。

演示顾客默认是「林予安」。店员默认是前台「何暖」，可在顶部把演示身份换成教练。老板在演示里对应馆主视角。三角色共用同一套数据：顾客约的课，店员和老板立刻能在名单与看板里看到。

取消规则在界面里写得很清楚：**开课前 4 小时**可免费取消，退回预占次数并释放名额。这个小时数可在老板端「营业规则」里改，改完立即按新规则执行。

---

## 怎么打开

- 用浏览器打开 `/workspace/fitflow-demo/index.html`
- 或在该目录运行 `./serve.sh`，再打开 http://127.0.0.1:8765/

顶部深色条是演示工具条，标有「演示样品 · 虚拟数据 · 非真实经营数据」，以及「试用视觉 / 色值未锁定，待创始人确认」。手机宽度下这两条提示也会保留，不会被收起。右侧可切换角色，并「一键重置演示数据」。这是演示功能，正式小程序不会保留。

### 核心流程怎么点

**看周课表并约团课**  
课表 → 选一天 → 点一节仍有余位的课 → 选择适用课包 →「预约本节团课」。约成后直接变为「已确认」，课包「可约」减 1，「预占」加 1。

**约满员课 / 候补（演示项）**  
种子数据里有一节改革器基础是满员的（常见为周五 12:00，重置后以页面显示为准）。点进去会看到不能再占名额，可加入候补。候补期间不预占次数。有人在窗口内取消后，按加入顺序转正并预占。界面已标明：候补不是每家店最小可销售产品的必交项。

当前演示里，林予安开场就排在该满员课的候补名单中，便于直接看结果。

**窗口内取消**  
我的预约 → 点一节距开课超过 4 小时的课（例如次日上午或晚间）→「窗口内取消」。次数退回，名额释放；若有候补，会看到转正。

**窗口外不能自行取消**  
我的预约 → 点即将开课、已过取消窗口的那节（傍晚重置时常见为当天 19:00 核心塑形；若打开时没有这样的自然课次，种子会补一节 1–2 小时后的一次性示范课，列表里会标明「窗口外取消示范」）→ 会提示已过窗口，顾客不能自行取消。

**预约私教**  
私教预约 → 选「裴衡」或「顾清越」→ 选日期和绿色可点时段。默认自动确认。若先到老板端把确认方式改为「手动确认」，再新约一节，状态会变成「待确认」。

**看余次**  
会员 → 打开课包。可约 / 预占 / 已核销会随预约、取消、签到变化。过期课包（叶浣溪的夏季团课卡，可在店员端会员档案查看）不能再约。林予安的「团课畅练」仅限团课，「私教精练」仅限私教；周栖迟的「改革器专项」不能用来约流动瑜伽。

**签到**  
顾客端只出示签到码，不能自己改核销结果。请切换到店员，在对应课次名单里点「签到」。签到后预占转为已核销，可约次数不再变化。

## 店员端怎么进

顶部切换到「店员」。默认身份是前台何暖，看到的是全店今日课次。若要看「我的排班」，请在顶部把演示身份换成某位教练，例如顾清越。

| 入口 | 路径 | 能做什么 |
|---|---|---|
| 今日课次 | `#/s/today` | 按时间看团课与私教，突出待签到、满员、候补 |
| 课次名单 | `#/s/session/课次编号` | 签到、批量签到、记缺席、窗口内/外取消、代约本节 |
| 待确认私教 | `#/s/pending` | 确认或拒绝（拒绝会退回次数并释放时段） |
| 查询会员 | `#/s/members` | 按姓名或手机号后四位查询余次 |
| 会员档案 | `#/s/member/会员编号` | 课包、预约、请假记录 |
| 代顾客预约 | `#/s/book` | 选择会员后代约团课或私教 |
| 手工请假记录 | `#/s/leaves` | 只登记原因和补课备注，不自动改课表 |
| 我的排班 | `#/s/schedule` | 教练看自己的课；前台会说明没有教学排班 |
| 店员中心 | `#/s/me` | 权限说明与常用入口 |

店员不能改全店课表、教室、卡项规则，也不能看经营看板。若直接打开老板页面，会看到权限说明，而不是把按钮藏起来充作权限。

### 建议走一遍的店员流程

1. 打开今日课次，点一节有「待签到」的课。
2. 为名单中的学员签到，或使用「批量签到」。
3. 再切回顾客（或打开该会员档案）核对余次：预占减少，已核销增加。
4. 用「代顾客预约」帮另一位会员约一节有余位的课。
5. 在「手工请假记录」里给会员登记一条请假和补课备注，确认课表不会被自动改掉。

## 老板端怎么进

顶部切换到「老板」。宽屏下左侧是完整管理菜单；手机宽度用底部「看板 / 课表 / 经营 / 设置」。

| 入口 | 路径 | 能做什么 |
|---|---|---|
| 经营看板 | `#/b/dashboard` | 今日约课、到课、消课、缺席、热门课、即将到期课包。数字由演示数据汇总，不是写死的大盘 |
| 课程管理 | `#/b/courses` | 查看、新增或编辑团课与私教课 |
| 周课表与排期 | `#/b/schedule` | 看按星期循环的模板、临时停课、新增周循环课、新增一次指定日期的课 |
| 教室管理 | `#/b/rooms` | 改名称与容纳人数。团课名额取课程上限与教室容纳的较小值 |
| 教练与排班 | `#/b/coaches` | 查看资料，增加私教可约窗口 |
| 会员档案 | `#/b/members` | 与店员共用会员查询，老板可继续发放课包 |
| 课包与卡项 | `#/b/packages` | 发放演示课包，查看可约 / 预占 / 核销 |
| 消课与消费记录 | `#/b/records` | 全店次数流水 |
| 今日课次 / 待确认 / 请假 | 同店员路径 | 老板拥有店员全部业务操作 |
| 营业规则 | `#/b/rules` | 取消窗口小时数、私教自动或手动确认 |
| 门店资料 | `#/b/store` | 名称、公告、介绍等 |
| 身份权限 | `#/b/staff` | 说明三角色权限，可添加演示店员 |

### 建议走一遍的老板流程

1. 先看看板数字，记住今日约课和消课数。
2. 打开营业规则，把私教改为「手动确认」并保存。
3. 切到顾客，新约一节私教，应进入待确认。
4. 再切到店员或老板，在「待确认私教」里确认或拒绝，观察次数和时段变化。
5. 回到看板，看数字是否跟着变。
6. 在周课表里新增一节不冲突的周循环课，或对某日课次做「临时停课」（会为未到店学员退回次数）。
7. 需要恢复最初数据时，点顶部「一键重置演示数据」。

## 关键状态说明

预约共用一条状态机：待确认 → 已确认 → 已到店 → 服务中 → 已完成。取消、拒绝、缺席会释放名额。

- 团课默认跳过待确认，直接已确认。
- 私教按门店配置走自动确认或手动确认，不另起一套状态。
- 约成预占 1 次；窗口内取消退回；签到后预占转为已核销；窗口外取消或缺席默认不退次。
- 不会出现负余额，也不会对同一预约重复扣次。
